🎯 Introduction

LAXA (Mon Langage Français) est un langage de programmation éducatif conçu pour faciliter l'apprentissage de la programmation en français. Il offre une syntaxe claire et intuitive, parfaite pour les débutants.

🇫🇷 100% Français

Syntaxe entièrement en français pour une meilleure compréhension

💡 Simple et Intuitif

Conçu pour être facile à apprendre et à utiliser

🚀 Interactif

IDE web intégré avec exécution en temps réel

🔧 Complet

Fonctions mathématiques, manipulation de chaînes, et plus

📝 Variables et Types de Données

Déclaration de Variables

En LAXA, les variables se déclarent avec le mot-clé variable :

# Déclaration avec valeur initiale
variable nom = "Alice"
variable age = 25
variable actif = vrai

# Modification d'une variable
age = 26
nom = "Bob"

Types de Données

Type Description Exemple
Nombres Entiers et décimaux 42, 3.14, -10
Chaînes Texte entre guillemets "Bonjour", "Hello World"
Booléens Vrai ou faux vrai, faux
Tableaux Listes d'éléments [1, 2, 3], ["a", "b"]
Dictionnaires Paires clé-valeur {"nom": "Alice", "age": 25}

🔢 Opérateurs

Opérateurs Arithmétiques

variable a = 10
variable b = 3

afficher a + b    # 13 (addition)
afficher a - b    # 7 (soustraction)
afficher a * b    # 30 (multiplication)
afficher a / b    # 3.333... (division)

Opérateurs de Comparaison

variable x = 10
variable y = 5

afficher x > y     # vrai (plus grand que)
afficher x < y     # faux (plus petit que)
afficher x >= y    # vrai (plus grand ou égal)
afficher x <= y    # faux (plus petit ou égal)
afficher x == y    # faux (égal à)
afficher x != y    # vrai (différent de)

Opérateurs Logiques

variable a = vrai
variable b = faux

afficher a et b    # faux (ET logique)
afficher a ou b    # vrai (OU logique)
afficher non a     # faux (NON logique)

🔀 Structures Conditionnelles

Condition Simple

variable age = 18

si age >= 18
    afficher "Vous êtes majeur"
fin_si

Condition avec Alternative

variable note = 15

si note >= 10
    afficher "Admis !"
sinon
    afficher "Recalé..."
fin_si

Conditions Imbriquées

variable note = 15

si note >= 16
    afficher "Très bien"
sinon
    si note >= 14
        afficher "Bien"
    sinon
        si note >= 12
            afficher "Assez bien"
        sinon
            afficher "Passable"
        fin_si
    fin_si
fin_si
💡 Astuce

N'oubliez pas de fermer chaque condition avec fin_si !

🔁 Boucles

Boucle Tant Que

La boucle tant_que répète un bloc de code tant qu'une condition est vraie :

variable i = 0

tant_que i < 5
    afficher "Itération " + i
    i = i + 1
fin_tant_que

Exemple : Compte à Rebours

variable compte = 5

tant_que compte > 0
    afficher compte
    compte = compte - 1
fin_tant_que

afficher "Décollage !"
⚠️ Attention

Assurez-vous que la condition de la boucle finira par devenir fausse, sinon vous créerez une boucle infinie !

🎯 Fonctions

Définir une Fonction

fonction saluer(nom)
    afficher "Bonjour " + nom + " !"
fin_fonction

# Appel de la fonction
saluer("Alice")
saluer("Bob")

Fonction avec Retour

fonction carre(nombre)
    retour nombre * nombre
fin_fonction

variable resultat = carre(5)
afficher "Le carré de 5 est " + resultat  # 25

Fonction avec Plusieurs Paramètres

fonction additionner(a, b)
    retour a + b
fin_fonction

variable somme = additionner(10, 5)
afficher "10 + 5 = " + somme  # 15

📋 Collections

Tableaux

Les tableaux permettent de stocker plusieurs valeurs dans une seule variable :

# Création d'un tableau
variable nombres = [1, 2, 3, 4, 5]
variable fruits = ["pomme", "banane", "orange"]

# Accès aux éléments (l'index commence à 0)
afficher nombres[0]    # 1
afficher fruits[1]     # banane

# Modification d'un élément
nombres[2] = 99
afficher nombres       # [1, 2, 99, 4, 5]

# Longueur d'un tableau
afficher len(nombres)  # 5

Dictionnaires

Les dictionnaires stockent des paires clé-valeur :

# Création d'un dictionnaire
variable personne = {"nom": "Alice", "age": 25, "ville": "Paris"}

# Accès aux valeurs
afficher personne["nom"]     # Alice
afficher personne["age"]     # 25

# Modification et ajout
personne["age"] = 26
personne["pays"] = "France"

afficher personne

⌨️ Entrées Utilisateur

Fonctions lire() et input()

LAXA propose deux fonctions pour récupérer les entrées utilisateur :

variable nom = lire("Votre nom: ")
variable age = input("Votre âge: ")

afficher "Bonjour " + nom
afficher "Vous avez " + age + " ans"

Conversion Automatique

Les entrées numériques sont automatiquement converties :

# Si l'utilisateur entre "16", c'est automatiquement converti en nombre
variable nombre = input("Entrez un nombre: ")
afficher "Racine carrée: " + sqrt(nombre)
afficher "Carré: " + (nombre * nombre)
✨ Fonctionnalité Avancée

Dans l'IDE web, une interface interactive apparaît automatiquement pour saisir les valeurs lorsque votre programme contient des fonctions lire() ou input().

🔧 Fonctions Intégrées

Fonctions Mathématiques

Fonction Description Exemple
sqrt(x) Racine carrée sqrt(16) → 4.0
abs(x) Valeur absolue abs(-5) → 5
round(x) Arrondi round(3.7) → 4
sin(x) Sinus sin(0) → 0.0
cos(x) Cosinus cos(0) → 1.0
tan(x) Tangente tan(0) → 0.0

Fonctions de Chaînes

Fonction Description Exemple
maj(texte) Convertir en majuscules maj("bonjour") → "BONJOUR"
min(texte) Convertir en minuscules min("HELLO") → "hello"
len(x) Longueur len("Bonjour") → 7

Fonctions Utilitaires

Fonction Description Exemple
random() Nombre aléatoire (0-1) random() → 0.7234...
date() Date actuelle date() → "2024-10-09"
heure() Heure actuelle heure() → "14:30:25"
annee() Année actuelle annee() → 2024

📖 Exemples Pratiques

Exemple 1 : Calculatrice

fonction calculer(a, b, operation)
    si operation == "+"
        retour a + b
    sinon
        si operation == "-"
            retour a - b
        sinon
            si operation == "*"
                retour a * b
            sinon
                retour a / b
            fin_si
        fin_si
    fin_si
fin_fonction

variable x = 10
variable y = 5

afficher "10 + 5 = " + calculer(x, y, "+")
afficher "10 - 5 = " + calculer(x, y, "-")
afficher "10 * 5 = " + calculer(x, y, "*")
afficher "10 / 5 = " + calculer(x, y, "/")

Exemple 2 : Calcul de Moyenne

variable notes = [15, 12, 18, 14, 16]
variable somme = 0
variable i = 0

tant_que i < len(notes)
    somme = somme + notes[i]
    i = i + 1
fin_tant_que

variable moyenne = somme / len(notes)
afficher "Moyenne des notes: " + moyenne

Exemple 3 : Programme Interactif

afficher "=== Programme de saisie ==="

variable nom = lire("Votre nom: ")
variable age = input("Votre âge: ")
variable ville = lire("Votre ville: ")

afficher "━━━━━━━━━━━━━━━━━━━━"

si age >= 18
    afficher "✅ Vous êtes majeur(e)"
sinon
    afficher "⏳ Vous êtes mineur(e)"
fin_si

Exemple 4 : Suite de Fibonacci

variable a = 0
variable b = 1
variable count = 10

afficher "Suite de Fibonacci (10 premiers termes) :"

variable i = 0
tant_que i < count
    afficher a
    variable temp = a + b
    a = b
    b = temp
    i = i + 1
fin_tant_que
